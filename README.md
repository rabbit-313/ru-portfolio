# Ru - ML/AI エンジニアリング

個人事業「Ru」のビジネスホームページです。MLモデルの開発、ML APIの実装、インフラ構築までを一貫して担当するMLエンジニア（FDE）のポートフォリオです。

## ライブサイト

**[https://rabbit-313.github.io/ru-portfolio/](https://rabbit-313.github.io/ru-portfolio/)**

## 提供サービス

- **MLモデル開発**: 推薦システム、画像処理など
- **ML APIとインフラ**: モデルのAPI実装、GCP上のパイプラインと運用基盤
- **FDEとして課題解決**: ビジネス側の課題整理からMLによる解決まで

## 技術スタック（サイト）

- HTML5, CSS3, JavaScript
- Font Awesome
- GitHub Pages + GitHub Actions

## ローカル開発

```bash
git clone https://github.com/rabbit-313/ru-portfolio.git
cd ru-portfolio
python -m http.server 8000
```
